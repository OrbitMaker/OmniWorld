# 经济生产与财政

经济主体、产业关系、生产库存定价、预算经费与经济闭环。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

版本 1.4　更新日期 2026年10月11日

### 主体与经济活动

**建议方案。** 经济由居民家庭、企业、政府、事业单位、商业银行和对外部门共同构成。未被玩家认领的主体继续生产、就业、消费和履职。

| 主体 | 基本活动 | 需要保存的经济状态 |
| --- | --- | --- |
| 居民家庭 | 工作、消费、储蓄、借贷和居住选择 | 收入、账户、资产、债务和需求 |
| 企业 | 采购、生产、招聘、销售、投资和缴税 | 库存、设备、产能、员工、合同及收支 |
| 政府 | 征收、预算、拨款、采购和保障 | 收入、预算、支出、债务与公共资源 |
| 事业单位 | 使用经费、人员和设施提供服务 | 预算、账户、资产、服务容量和待办 |
| 商业银行 | 支付、存贷款、计息和风险管理 | 客户账、贷款、结算资金和资产负债 |
| 对外部门 | 贸易、外部采购、运输和汇率传导 | 订单、合同、价格和交付条件 |

### 初始状态与产业关系

从现实观测建立人口、就业、收入、消费、产业、设施、产能、财政、资产与债务基线。存量、流量和生产增加值分别计算，GDP不能当作开局可分配货币，也不能用交易额总和替代。

产业链可参考投入产出关系。建材、能源、交通、农业、制造、商业和服务之间建立采购与供给连接，具体系数和地区价格需要采集与校准。

### 生产库存与定价

生产消耗原料、能源、劳动、设备使用能力和时间。采购、库存预留、生产、交付、付款和资产转移分别记录，避免只用一段文字宣布生产完成。

价格由成本、企业报价、需求、库存、合同及对应定价规则共同变化。资源不足时可能出现排队、减产、涨价或替代采购，实际结果由规则及经营选择形成。

### 财政和机构经费

**建议方案。** 财政参考一般公共预算、政府性基金预算、国有资本经营预算和社会保险基金预算，并建立中央与地方、各级地方之间的支出责任和资金关系。[S1]

第一版四本预算的实现深度待定。学校、医院等按自身类型定义经费来源和用途；校长个人工资和存款与学校账户分别管理。

预算流程建议为：形成预算、获得授权、分配经费、承诺支出、完成交付、支付记账、汇报结果。预算不足时申请调整或降低计划规模，政府保障和危机处置也受资金、人员与设施约束。

### Token兑换与建设经济

**已确定。** 玩家货币可以兑换系统Token，玩家自有Token可以兑换系统货币；玩家可使用Token建设楼房、高速公路及其他设施。开局基础建设由系统提供，兑换比例、Token计量单位和项目价格待定。

**建议方案。** 兑换分别记录货币扣减或到账、Token交付或增加、系统交易对手及报价版本。系统供给Token、接收Token和支付货币的来源另行确定。项目同时保存Token预算和实际消耗，以及游戏中的资金、材料、劳动、进度和资产变化；与施工支出如何折算尚待讨论。公共项目资金与玩家个人账户继续分别管理。详情见[16 城市建设与Token兑换](16-construction-token-exchange.md)。

### 经济闭环与校验

就业产生收入，消费形成订单，企业采购生产并发薪和缴税，政府与事业单位提供服务，银行处理支付与融资。公共制度和结算先建立，再接入这一生活循环。

检查项包括资金转移两侧对应、账户与债务匹配、投入与库存变化对应、生产和服务受容量限制、认领对象没有重复新增资产、现实消息沿明确渠道影响经济。
