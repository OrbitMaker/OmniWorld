# 现实资料与游戏同步

现实档案、来源版本、消息事件、资料周期及历史校准。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

版本 1.5　更新日期 2026年10月11日

[返回项目主文档](00-overview.md)

### 现实档案与开局基线

**已确定。** 世界范围覆盖全球，地理、人口、产业和社会生活资料来自各现实地区；制度骨架参照中国体制，在游戏中形成统一机构及行政体系。既有区域基础调研继续作为来源，完整全球地区及实体数据库仍需采集并建立映射。

- 机构：现实名称、职责与设施作为资料来源；游戏机构按统一制度建立，保存独立游戏身份和现实参照关系。

- 地区：全球行政区划、地理边界、资源、产业与公共设施；原始国家代码、行政代码、来源层级及游戏省市县映射分别保存。

- 社会经济：人口分布、家庭、就业、收入、消费、生产和财政。

- 公共服务：学校、医院等单位与人员、资金和容量资料。

- 环境：地形、土地、天气、流域、交通、能源和灾害。

### 数据状态与版本

**建议方案。** 区分可核验事实、统计估计、模型推断和游戏生成内容。缺失字段留空或标注估算，避免把未知信息变成真实档案。

每条记录保留来源地址、发布者、统计期、发生时间、发布时间、生效时间、采集时间、单位、范围、版本与修订关系。不同年份资料进入同一开局时点时，记录估算方法和误差。

合成人物用于表达统计结构与社会行为，其姓名、个性和私人经历属于游戏生成。不能将合成内容标成对应现实个人的真实生活。

### 资料周期与模型周期

资料采集和角色决策分别配置。学校资料可能按月或公告更新，角色可以每几个游戏小时判断一次；提高游戏倍率不会使现实产生同等速度的新资料。

现实发布、资料采集、游戏业务推进和模型思考是四种不同节奏。后台分别设置采集周期、事件审核规则、角色决策触发和调用预算。

### 从现实消息到游戏事件

**建议方案。** 获取消息、核对来源、抽取事实、去重、定位地区与对象、审核影响渠道、生成事件、执行和跟踪反馈。

- 政策资料先保存现实来源与适用地域，再确认是否转为游戏内规则及其生效范围；现实国家的新规不自动在游戏全球生效。

- 灾害或设施事实进入已确认的地点与状态，损失大小另有观测或模型依据。

- 统计发布用于观测或校准，不能直接替代已发生的玩家交易。

- 观点和预期影响获知消息的角色选择，不自动改变所有人的资金或情绪。

- 油价变化通过采购、库存、合同和经营选择传导到成本与报价。

- 学校招聘公告或政策通过岗位、预算和服务需求影响对应机构及家庭。

### 分叉历史与校准

玩家介入后，世界形成自己的历史。现实档案更新、外部事件输入和模拟参数校准分别记录；避免现实新数据无记录地覆盖玩家已形成的资产、关系与合同。

同一新闻的转载不得反复施加影响，开局快照已经包含的事件也不得重复计入。更正和撤回保留关联版本；未知影响标注为待核验。

验收要求：可核验部分尽量吻合、未知部分明确标识、变化有来源、模拟结果可追溯和校准。现实未来与游戏未来不要求完全一致。

**建议方案。** 全球省级候选数量及来源快照在[17 全球疆域与省级单位](17-global-regions.md)维护。名录缺项、特殊地区、海外属地和范围重叠逐条核验；游戏历史中已有的人口与资产在拆并时通过映射迁移，避免重复生成。
