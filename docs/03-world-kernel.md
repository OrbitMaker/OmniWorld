# 世界内核与统一对象

身份、状态、关系、行为规则、世界时间与状态连续性。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

### 对象与最低状态

**建议方案。** 使用统一对象标识，避免机构改名、岗位换人或节点退出时重建身份。现实名称、别名、有效时间和资料来源作为对象属性。

| 对象 | 最低状态和关联 |
| --- | --- |
| 辖区与地点 | 类型、边界或坐标、所属地域、邻接、设施和版本 |
| 机构与组织 | 类型、职责、辖区、关系、岗位、预算、资产和待办 |
| 岗位与任职 | 所属机构、职责、资格、权限、在任角色和任期状态 |
| 人物 | 身份、年龄、技能、位置、关系、需求、账户和运行状态 |
| 家庭与户 | 成员、家庭关系、住所、收支、资产、照护与共同需求 |
| 设施与资产 | 所有者、运营者、位置、容量、可用状态和使用约束 |
| 账户与债务 | 所属主体、所属银行、币种、余额、限制、债权和版本 |
| 商品与库存 | 品类、数量、位置、所有者、成本及预留状态 |
| 合同与事项 | 当事人、条件、资源、期限、处理阶段和关联事件 |
| 规则与事件 | 适用范围、版本、时间、来源、执行结果和关联对象 |

### 关系与行动规范

家庭关系、雇佣、产权、机构隶属、监管和服务覆盖分别存储，并保留生效和终止时间。机构主体、其办公或服务设施、所在地点及岗位任职是相互关联的不同对象。

每种动作需要定义：谁发起、对谁操作、读取哪版状态、需什么资格和资源、用多久、是否需要审批、成功改变什么、失败返回什么、会通知哪些对象。

动作流程建议为：接收请求、检查身份与权限、核对时间与当前版本、检查预算和资源、执行或排队、写入事件、通知受影响对象。唯一请求编号用于识别重试。

### 时间与状态连续性

**已确定。** 后台可以设置加速或不加速。**建议方案。** 一个世界使用同一游戏时钟，文字、三维和分布式节点共用；支持自定义倍率、暂停和恢复，365倍速保留为候选预设。

**建议方案。** 工资、利息、合同、服务日程按各自业务周期执行；角色思考、现实采集和三维渲染使用各自调度参数。改变倍率时记录切换时点，已有期限保持其游戏时间含义。

- 状态包含版本，过期方案提交后需要复核或重算。

- 保存机构、人物、资产、正在执行的计划和未完成事项。

- 用快照与事件记录恢复，恢复后能够核对交易和待办。

- 规则版本、必要的模型输出和随机种子保留，支持解释及回放。
