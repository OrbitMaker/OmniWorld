# 全球统一世界模拟游戏设计与开发总纲

我们要建立覆盖全球的社会模拟游戏，目标为全世界大一统。制度参照中国体制，游戏内使用中性国家名称，由代码、AI智能体和玩家共同运行。

主文档维护概括、关键决定和模块目录，详细规则、来源、待定及验收保存在子文档。当前处于基础调研与方案设计阶段，游戏原型尚未开发。

## 项目概括

中央到基层采用统一行政体系，覆盖全球地区、机构、家庭和个人，保留现实社会因果链与连续历史。按现有一级行政区映射，暂估约3,800至3,900个省级单位，最终目录待核验。

**已确定。** 现实中的区域战争、暴乱、游行、民众矛盾、治安及刑事案件等事件均可发生；中央政府通过政府及国家暴力机关维持社会基本稳定，平台保留核心控制能力。

**已确定。** 玩家从普通民众起步，教育、工作、生活和晋升遵循现实因果链。政府录用、晋升、领导职责、任期和换届参照适用制度，按岗位记录资格、产生方式、权限与任免程序。

**已确定。** 玩家同时承担市或省的算力和Token供给，经中央计算中心分配地区领导岗位，其他玩家可加入。市省资源分别定额保障政府运行；资源贡献与现实任职程序的衔接待细化。

**已确定。** 开局由系统提供基础建设，玩家可使用Token建设楼房、高速公路及其他设施；玩家货币可兑换系统Token，玩家自有Token可兑换系统货币。设施清单、Token计量、兑换比例与建设定价待定。

**已确定。** 文字页面和三维页面连接同一个世界，时间倍率由后台选择。三维引擎、银行明细托管、人口模拟精度及首批运行范围等仍待定。

## 当前重点与待定事项

建设顺序保持自上而下：先形成制度、机构和权限，再贯通财政及公共服务，接入人物就业与生活，最后扩展地区规模和运行精度。

1. 选择首批全球地区、机构和贯通行业，建立统一省级映射，补齐制度参照、服务容量及现实资料。

2. 建立政府岗位制度表，细化录用、晋升、领导履职、换届、任期内调整及资源任职衔接。

3. 贯通预算、机构、岗位、服务、家庭及银行交易，验证身份、账务和状态连续性。

4. 测量市省承接所需算力、输入输出Token、吞吐、持续预算及接替容量，再确定数值配置。

5. 定义开局基础设施、Token单位与双向报价，建立楼房和高速公路项目模板，贯通建设及兑换流程。

阶段计划、全部验收条目、待定问题和后续任务见 [14 开发计划验收与待定事项](14-roadmap-open-questions.md)。
