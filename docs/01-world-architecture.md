# 世界目标与总体架构

现实背景、覆盖层级、核心决定、还原边界与八个工程模块。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

### 世界目标与覆盖层级

**已确定。** 目标为全世界大一统。游戏采用中国体制作为制度参照，不完整复刻中国；全球现实地区进入统一的省级及以下行政体系，游戏内不使用“中国”作为国家或世界名称。保留中央、省级、市级、县级、基层、机构、家庭和个人层级，玩家按角色权限参与。现实资料支撑地理、社会生活、经济条件与因果关系，游戏内形成自己的机构和历史。

- 全球地区和机构逐步建立目录与关系；原始行政代码与游戏地区身份分开，细化程度、资料完整度和运行能力分别标识。

- 同一人物、家庭、机构或资产跨视角保持身份连续，切换视角不会生成第二份对象。

- 可观察的层级与可控制的权限分开。看到一座城市的指标，不自动取得这座城市的治理权。

- 开局基线、现实资料、游戏变化及玩家创造的历史分别保存。游戏未来属于模拟结果。

### 已确定的核心方向

| 方向 | 当前决定 |
| --- | --- |
| 建设顺序 | 自上而下建立国家制度、政府、公共机构与秩序，再接入居民和企业生活 |
| 世界定位 | 制度参照中国体制，目标为全世界大一统，不完整复刻中国；游戏国家使用中性名称 |
| 现实基础 | 全球地理及社会生活资料进入统一世界，保留现实行为与因果链 |
| 全球省级 | 各来源地区映射为省级等效单位，ADM1口径暂估约3,800至3,900个，最终映射清单待核验 |
| 冲突与风险 | 允许区域战争、暴乱、游行、民众矛盾、治安和刑事案件等事件发生，事件范围不封闭 |
| 中央底线 | 中央政府保有政府与国家暴力机关的实际治理及处置能力，平台掌握核心控制，维持社会基本稳定 |
| 玩家开局 | 玩家从普通民众起步，生活、工作、教育与晋升遵循现实的行为和因果关系 |
| 机构开放 | 玩家可经教育、考试等现实路径进入对应工作；事业单位开放；政府工作与领导岗位按角色及分配规则开放 |
| 政府制度 | 录用、晋升、领导职责、任期与换届均参照现实制度，按岗位维护程序 |
| 地区领导 | 玩家承担市、省对应的算力及Token资源，可由中央计算中心分配市长、省长岗位，其他玩家可加入该地区 |
| 分布式 | 地区、机构或任务接入同一世界；计算与Token供给有定额，中央计算中心统一分配并保障政府基本运行 |
| 双页面 | 提供文字游戏页面及类似我的世界的三维画面页面 |
| 世界时间 | 后台可以选择加速或不加速；具体倍率、暂停和恢复按建议方案另行实现 |
| 持续记录 | 每轮有效讨论更新相关模块子文档，主文档维护概括与目录，并保留变更记录 |
| 开局建设 | 系统在开局提供基础建设，设施清单和范围待定 |
| 城市建设 | 玩家可使用Token建设楼房、高速公路及其他设施 |
| 资源兑换 | 玩家货币可兑换系统Token，玩家自有Token可兑换系统货币，比例与计量方式待定 |

### 模拟真实性与实现边界

**已确定。** 制度采用中国体制参照，覆盖全球统一世界；地理与社会运行以现实为基础，现实冲突、风险及治理过程继续属于模拟范围。真实性分别检查制度结构、空间设施、数量与社会因果关系。真实资料名称与游戏名称、现实国家机构与游戏中央地方机构分别保存；合成人物经历及模拟未来属于游戏内容。具体还原精度与映射验收指标待定义。

**待定。** 全球居民是否从开始就全部拥有独立身份与账户，还是按群体运行后按需展开；现实同步与自由演化是否设为独立模式；首批细化范围和可接受误差。不能把少量代表人物当成全球逐人模拟已经完成。 开局统一状态、全球省级映射与按人口面积拆并规则见[17 全球疆域与省级单位](17-global-regions.md)。
