# 文字页面与三维世界

双入口共用状态、局部加载、引擎候选及时间体验。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

版本 1.3　更新日期 2026年10月11日

[返回项目主文档](00-overview.md)

### 两种入口与共同状态

**已确定。** 提供文字页面及类似我的世界的三维画面页面。**建议方案。** 两者共用人物、机构、岗位、资产、账户、关系、记忆、事件和时间。

| 页面 | 主要内容 | 可执行交互 |
| --- | --- | --- |
| 文字页面 | 层级地图、社会新闻、机构卡片、人物档案、经济指标、事项和历史 | 查看、对话、申请、计划、经营及岗位决策 |
| 三维页面 | 街区、校园、医院、网点、住宅、设备和在场角色 | 行走、谈话、工作、会议、服务和建设 |

文字页发现学校教师紧缺，进入校园与相同角色互动，提交授权范围内的招聘计划；规则执行后两种页面显示同一岗位和经费结果。

### 国家视角与局部加载

**建议方案。** 全国社会状态持续运行，三维精细加载玩家附近地点。离开校园后可停止细致动画和碰撞，学校的服务与社会经济活动继续按规则推进。

行政区划、土地、交通、河流、能源及设施拓扑作为空间基础。三维建筑绑定对应地点与机构，玩家贡献场景和建筑需要与现有身份、资产和权限对接。

### 我的世界与技术候选

Minecraft本体不作为开源代码使用。官方取消Java版混淆不改变其许可；独立游戏需要使用许可明确的引擎、自有代码和可使用的素材。[S5]

| 候选 | 主要路线 | 需验证的事项 |
| --- | --- | --- |
| Voxelize | MIT许可，网页体素和多人世界，TypeScript客户端与Rust服务端 | 网页性能、接口、场景与社会后台连接 |
| Luanti | 开源方块游戏引擎，核心主要为LGPL 2.1或后续版本 | 独立客户端、模组能力、素材与各组件许可 |
| Godot加Voxel Tools | Godot生态，Voxel Tools为MIT许可 | 自定义城市室内、联机、角色及发布流程 |

这些是候选方案，尚未选型。[S6][S7] 它们提供画面和空间基础，国家制度、机构流程、经济及现实同步仍需单独开发。

### 时间与场景体验

365倍速下，现实10分钟约对应游戏60.8小时，现实约49秒对应游戏5小时。高倍率会影响谈话、通勤、上课和服务体验，需要验证动作时长如何映射；倍率由后台选择。

三维帧率、网络同步周期、游戏业务时间和模型决策间隔分别配置。**待定。** 浏览器或客户端、目标设备、角色表现、建筑编辑程度及高倍率交互规则。
