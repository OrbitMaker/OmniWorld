# 国家制度与公共秩序

组织骨架、中央底线、公检法、冲突事件及社会基本稳定。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

### 建设依赖与组织骨架

**已确定。** 制度和公共机构构成居民生活的前置依赖。统一治理目标覆盖全球，制度参照中国体制，游戏内使用中性国家名称。来源国家的地区映射到统一省级体系，不自动成为独立国家政府。 **建议方案。** 首批收缩机构数量和业务细节，保留从世界中央到地方基层的职责关系；街区用于检验制度能否支撑生活。原有国家是否保留为地理分类及如何展示另行确定。

- 建立辖区目录、边界版本、机构目录和岗位目录。

- 分别记录行政隶属、业务指导、垂直管理、监督、出资、监管及服务范围。

- 将党委、人大、政府、政协、监察、法院、检察等体系作为分别建模的覆盖对象，具体关系依据公开有效资料采集。

- 区分行政机构、事业单位、企业、社会组织和基层自治组织；按各自制度接入。

- 国家到基层的组织网络不能只依赖一个上下级字段；跨地区服务和设施网络单独表示。

### 中央保留能力与开放边界

**已确定。** 中央保留核心秩序和底线处置能力，能够通过政府机构及国家暴力机关处理社会冲突与危机，保持社会基本稳定。公检法和国家暴力机关由平台掌握核心控制，事业单位允许玩家参与。政府治理能力须体现在世界中的机构、权限、资源和行动结果。

**已确定。** 玩家可以进入政府工作；承担地区算力和Token供给的玩家可由中央计算中心分配市长或省长岗位。**待定。** 其他政府岗位开放范围、地区领导任职资格与社会晋升路径的衔接、核心岗位观察或辅助权限、危机介入条件。中央保留底线能力，地区日常运行可以分布式承担。

### 可执行规则目录

**建议方案。** 首批规则覆盖身份登记、产权登记、合同、岗位授权、预算、货币与结算、服务资格、投诉和争议处理。每条规则至少写明适用对象、执行主体、必要条件、有效时间和结果。

- 身份与产权：登记、查询、变更、继承及有依据的冻结或限制。

- 合同：成立条件、当事人、标的、金额、交付日期、履行与违约状态。

- 财政：预算授权、拨款条件、支出用途、执行记录和反馈。

- 岗位权限：能读取什么、能提交什么、需要谁审核、是否可委托。

- 服务资格：谁可以申请、由谁受理、需要哪些资源、完成标准是什么。

- 争议程序：受理、核查、处理、执行、反馈及后续申诉的状态。

### 公检法与争议处理

**建议方案。** 公安、检察、法院分别配置职责、权限、处理阶段和记录。事项按对应制度转办，不将所有争议归为同一机构的一步处理。

第一轮可以用一件明确标为测试的合同或采购纠纷贯通：提出事项、确认受理权限、收集已有证据、按规则作出处理、执行相应资金或权利变化、记录反馈。资金和资产变化必须由执行代码落实。

### 现实冲突与基本稳定

**已确定。** 游戏允许发生现实社会可能出现的各种不利事件，包括但不限于区域战争、暴乱、游行、民众之间的矛盾、各类治安事件和刑事案件。上述示例不构成封闭清单，世界能够持续产生新的事件及连锁后果。

**已确定。** 中央政府具有使用政府机构和国家暴力机关应对、处理并解决这些问题的能力，承担维持社会基本稳定的职责。局部风险与冲突可以发生，公共秩序和基本社会运行由持续治理来维持。

**建议方案。** 按具体行为、影响、证据和适用规则分别建模，游行和公共表达单独记录其诉求、参与和秩序状态；违法、暴力或损害行为进入对应处置流程。一个事件可以同时关联多种类型，分类随调查结果更新。

| 事件类型 | 范围示例 | 需要联动的世界状态 |
| --- | --- | --- |
| 区域战争与武装冲突 | 区域性战争、外部冲击、局部武装冲突 | 人口迁移、设施损失、供应链、财政和公共服务 |
| 暴乱与严重秩序扰动 | 群体暴力、设施破坏、公共秩序中断 | 人员安全、交通、设施、服务容量和恢复进度 |
| 游行与公共表达 | 集会、游行、集体诉求表达 | 诉求、参与规模、沟通反馈、交通和秩序状态 |
| 民众矛盾与社会纠纷 | 邻里、家庭、劳资及群体间矛盾 | 关系、情绪、合同、调解和争议处理 |
| 治安事件与刑事案件 | 各类治安事项和刑事案件 | 受理、调查、证据、机构协作、处理和执行状态 |
| 其他风险与不利事件 | 灾害、事故、公共卫生、经营与金融风险等 | 对应资源、损失、责任、救助和恢复事项 |

**建议方案。** 每个事件记录来源、真实性标识、游戏时间、地点、涉及主体、起因、当前阶段、影响范围、损失、处置机构、已投入资源和后续事项。现实事实、模拟事件和测试输入分别标识，模拟事件不得回写为现实事实。

处置流程建议包含以下阶段，具体权限、程序和触发条件继续细化。

1. 发现或受理：形成事件记录，记录已知信息与尚待核实的情况。

2. 研判与协作：按职责确定承办和协作机构，必要时进入地方与中央协调流程。

3. 决策与执行：政府通过沟通协调、公共服务、行政管理、调查司法及按权限使用强制力量等方式处置，记录决定、资源和实际结果。

4. 稳定与恢复：跟踪秩序、生活必需供给、医疗和其他基本服务的恢复，继续处理救助、赔偿、重建和未结案件。

5. 反馈与复盘：保留人物经历、社会关系、经济损失和制度调整，使后续行为受到事件影响。

**建议方案。** 将人员、预算、设施、信息、调配时间和执行能力纳入响应过程。政府的稳定保障能力通过可执行流程、资源供给和跨层级协作实现；事件处置耗时、损失和恢复进度能够在游戏中观察及核对。地方自主处置边界、中央介入条件、区域战争主体与规模、事件频率和稳定指标待定。

### 稳定保障与技术管理

公共服务连续性、争议有处理路径和关键节点可接替，是底线保障的基本检查项。战争、暴乱、游行、治安及刑事案件，以及失业、短缺、经营失败和社会矛盾，都可以成为实际影响人物与机构的事件。政府须能够响应并维持基本秩序，处置后的损失、关系变化和恢复事项持续保留。

**建议方案。** 将平台技术管理权限与游戏政府角色权限分别记录。平台维护时钟、授权、存档和故障恢复；游戏机关按职责、程序、预算和资源履职。任何人工修正都留下修改对象、原因和时间。
