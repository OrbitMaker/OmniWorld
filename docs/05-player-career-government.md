# 玩家生活与政府任职换届

普通民众开局、社会生活、录用晋升、领导职责、任期换届及资源任职衔接。本模块保留已确定要求、建议方案和待定事项，作为该主题的详细记录。

### 普通民众开局与资格取得

**已确定。** 玩家开局为普通民众，通过社会行为参与生活、求学、就业和晋升；可以经高考等多种路径形成进入政府工作的条件。民众的生活、工作与晋升环节及其因果关系以现实为依据，事业单位开放可玩。

**现实制度依据。** 高考对应升学环节，公务员录用、政府工作岗位和领导职务分别具有资格、考察及任职程序。一般公务员考试录用和领导职务晋升在《公务员法》中分别规定。[S9] **建议方案。** 将教育经历、毕业资格、工作能力与经历、职位空缺、招录或选拔、考察、任职与考核分别写为可执行事项；按具体岗位接入适用规则。

### 现实生活工作与晋升链

**已确定。** 工作链、行为链和因果链保持连续，玩家的选择须通过人物、家庭、学校、雇主及政府机构的实际流程形成后果。

**建议方案。** 开局人物关联身份、年龄、家庭、住所、健康、教育、技能与资产；起始年龄、家庭条件和可选地区待定。行动受到资格、时间、资金、岗位及服务容量约束。

| 路径 | 行为与工作链 | 需要保留的结果 |
| --- | --- | --- |
| 普通就业 | 求职、岗位筛选、招聘、合同、到岗、劳动与发薪 | 雇佣关系、时间、工资、技能、评价与社保事项 |
| 教育与政府工作 | 学习、高考、升学、毕业、岗位资格、招录或选拔、考察与录用 | 成绩、学历、资格、录用状态、岗位与任职经历 |
| 职业晋升 | 完成工作、积累能力与实绩、满足任职条件、参与选拔、完成任职 | 考核、资历、职责、职务职级、待遇及责任 |
| 社会生活 | 居住、消费、交往、家庭照护、公共服务及迁移 | 收支、需求、关系、健康、住所与服务记录 |

**建议方案。** 每条链保存前置条件、发起行为、承办对象、资源消耗、完成或失败原因、状态变化及后续机会。学习和任职经历跨岗位保留；考试、就业与晋升允许失败、延迟或转向其他路径。AI提出意图后，由规则执行真实状态变化，叙述与人物、账务及机构记录一致。

### 任职权限与交接

岗位授权包括信息范围、预算使用范围、可执行动作、审批关系和责任。个人资金、机构资金和公共资源分别记账。

- 交接机构现有档案、资产、预算、关系、已签合同和待办。

- 接管已有角色或岗位，不复制相同职位、人口或资产。

- 离任时收回岗位权限，保存任职期间的决定和后果。

- 机构和岗位持续存在；玩家退出后由默认策略、智能体或接任者继续运行。

- 履职评价、晋升、免职、资格暂停与争议处理参照适用现实制度；具体岗位参数和游戏执行实现继续细化。

### 资源贡献与地区领导任职

**已确定。** 玩家主动承担某个市或省的运行资源，提供与地区规模相匹配的计算配置和Token供给，可以担任市长或省长；地区与岗位由中央政府计算中心统一分配。其他玩家能够加入该城市或地区，在同一世界生活、就业或承担岗位。

资源贡献与领导岗位挂钩属于本游戏已确定的任职机制。现实社会晋升路径同样保留，两者的资格衔接、岗位空缺、考核、任期、调任及退出规则待细化。该游戏机制单独标识为资源贡献任职规则。

**建议方案。** 玩家提交地区承接申请和资源承诺，中央核验供给、核定职责与容量，再完成分配、任职和机构交接。申请失败保留原因；地区领导按岗位权限履职，居民、资产、机构和社会历史继续使用已有身份。

### 玩家与运行节点的区别

**建议方案。** 角色决策、资料维护、计算托管与Token供给分别登记，资源贡献和地区任职通过中央分配记录关联。同一玩家可以同时作为地区资源贡献者和市长或省长；合作提供资源、本人任职或分工任职的规则待定。

玩家取得地区岗位时，按中央核定的职务获得治理权限；计算托管权限、岗位权限、底层账务权限及平台管理权限分别执行。任职后遵循岗位规则，机构与居民的状态变化保留依据和记录。

### 政府制度的现实参照

**已确定。** 政府录用、晋升、领导职责、任期及换届参照中国体制和适用现实规则，在游戏的统一全球框架中运行，不逐国复制来源国家的制度。按岗位记录所采用制度版本及游戏生效日期；机构届期、个人任期、职务、职级和算力托管期限分别记录。游戏机构与现实参照机构分开，全球各地区教育及岗位条件的具体映射待细化。

### 公务员录用与领导干部晋升

**现实制度依据。** 《公务员法》分别规定录用、任免和职务职级升降。一般考试录用以编制和职位空缺为前提，包含公告、资格审查、考试、复审、考察、体检、公示及审批或备案，新录用公务员试用期为一年。事业单位招聘适用相应制度，高考仍处于教育路径。[S9]

**现实制度依据。** 领导干部选拔任用包括研判动议、民主推荐、考察、讨论决定及任职手续；需要人大选举或决定任命的岗位继续履行相应程序。晋升领导职务、晋升职级与普通招聘分别运行。[S9][S11]

**建议方案。** 人物保存学历、资格、工作经历、考核、培训、回避关系及处分记录；岗位保存机构、职责、编制职数、空缺、任免机关和资格条件。每个环节产生结果、失败原因和可追溯的任职依据。招录年龄、学历专业、经历年限等条件按对应公告和岗位规则核定，不设一个适用于所有岗位的门槛。

### 政府领导职责与组织关系

**现实制度依据。** 国务院统一领导地方国家行政机关。地方政府实行行政首长负责制，领导所属部门及下级政府，并向本级人大及上一级国家行政机关负责、报告工作；县级以上政府在人大闭会期间向本级人大常委会负责、报告工作。省长、市长由本级人大选举产生，党委推荐、政府履职与人大监督各有程序。[S10][S11]

**建议方案。** 市长、省长的工作进入政府议事、预算、部门执行与监督流程。每项职责关联提出者、决策权限、程序、执行部门、资金、完成情况及问责依据。分别建立党委、人大及其常委会、政府、监察机关、法院和检察院等对象，按适用制度记录职责和关系；党委书记与政府首长分别建岗位。

| 治理工作 | 游戏中需要执行的链条 |
| --- | --- |
| 发展与财政 | 提出目标、形成计划和预算、履行审批、部门执行、统计与监督 |
| 公共服务 | 汇总需求、核定政策和资源、安排部门执行、评估服务结果 |
| 社会秩序与应急 | 识别事件、核验权限、协调处置、记录损失和恢复、接受监督 |
| 人事与组织 | 识别空缺、核查资格、依权限选拔或任免、交接与考核 |
| 政府报告与监督 | 汇总工作和资金结果、报告、回应质询与意见、整改 |

### 任期与换届的时间规则

**现实制度依据。** 地方人大每届任期五年，地方政府届期与本级人大相同。个人中途调任、辞职或免职与机构换届分别处理。党政领导干部个人任期和交流规则另有适用范围；相同岗位的连续任期限制、累计任职年限及特殊规定须按具体岗位维护。[S10][S11][S12]

**建议方案。** 用游戏日历保存届次、选举或任命生效日、个人到任日、届满日、考核日及离任依据。加速只改变现实时间与游戏时间的对应关系，法定期间仍在游戏日历内计算。政府届期、个人任职、资源承诺到期和节点离线事件各自触发对应流程。

### 换届交接与任期内调整

**建议方案。** 换届依次记录准备与岗位设置、推荐提名和考察、适用的选举或任命、生效与公告、交接及新班子履职。会议主体、候选人、表决及法定成立条件按岗位适用制度配置；市长、省长采用本级人大选举路径。[S10][S11]

交接包括权限、档案、财政预算、资产、债务、合同、待办和进行中的事件。换届延续既有机构和社会状态。任期内缺位、代理、补选、调任、辞职、免职及问责分别设流程；具体代理和补选规则需按相应机构法律补齐。

### 资源贡献与现实任职程序的衔接

**已确定。** 保留资源贡献者承担市省算力和Token、中央统一分配地区及岗位的游戏机制，同时落实本轮确定的现实录用、晋升、领导职责和换届参照。

**建议方案。** 资源核验和中央分配记录先形成承接及岗位申请依据，随后接入相应资格、推荐提名和选举任命程序。资源供给与人物任职各自维护状态；人物离任后，地区运行资源仍需交接或替换。资源接替按运行授权执行，正式岗位任免按对应制度执行。

**待定。** 资源贡献在候选资格和岗位分配中的具体作用、多人合作供给、资格未满足时的承接方式，以及换届后继续供给或退出的规则。

### 本模块的验证要求

**建议验收。** 分别演示普通人物录用、职级或领导职务晋升、一次政府工作审批与执行、一次换届交接、一次任期内缺位及资源接替。检查各事件的前置资格、执行主体、任免依据、生效时间、权限和结果连续性。以上为待开发的验收要求。
