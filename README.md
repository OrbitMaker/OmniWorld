# OmniWorld · 万象世界

**我们正在构思建设中，欢迎大家一块参与。**

联系邮箱：[13390g@gmail.com](mailto:13390g@gmail.com)

我们希望建立一个覆盖全球、以全世界大一统为目标的社会模拟游戏。世界采用统一的中央与地方行政体系，玩家从普通民众起步，参与学习、工作、生活、建设和治理；代码、AI智能体与玩家共同维持世界运行。

## 当前进度

项目处于构思、现实资料调研和方案设计阶段。当前仓库提供总纲、模块详情、参考资料和待定问题，尚无可运行的游戏原型。

项目文档版本：**1.7**。更新日期：**2026年10月11日**。各模块保留自己的版本和变更记录。

## 正在设计什么

- **世界与治理：** 全球地区纳入统一行政体系，保留社会事件、公共秩序和现实因果链。
- **玩家生活：** 普通民众开局，学习、就业、晋升与政府任职形成连续的行为链。
- **经济与建设：** 产业、生产、财政、银行和城市设施互相关联，Token与游戏货币的兑换、建设定价仍待细化。
- **资源与协作：** 玩家可以承担地区算力和Token供给，由中央计算中心分配资源与岗位，其他玩家可以加入。
- **世界呈现：** 文字页面与三维页面连接同一个世界，时间倍率可以配置。
- **规模与成本：** 按现有一级行政区映射，暂估约3,800至3,900个省级单位；最终疆域目录、模拟精度及资源定额仍待核验。

这些是正在设计的目标与规则。已确定、建议方案和待定事项在各模块中分别标注。
